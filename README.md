# Scoreboard
A simple scoreboard application, totally vibe coded.  
Participants and scores are saved in each visitor's own browser via localStorage.  
The site has no shared database so each visitor sees their own separate scoreboard.  

There's a limit for the number of participants based on the amount of emojis in App.jsx. 
I might update the app later on for administrating the amount of participants and the emoji set but right now I'll stick with editing the App.jsx file.
